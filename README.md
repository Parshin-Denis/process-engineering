# Windows приложение для работы с технологическими картами и инструментами завинчивания.

## Описание работы
Приложение служит для создания и редактирования технологических карт, используемых при сборке автомобилей, группирования их в хронологическом порядке по постам,
а также для работы с инструментами завинчивания. Все данные приложения хранятся в базе данных, доступ к которой реализован с помощью приложения
[Production process service](https://github.com/Parshin-Denis/production-process-service.git).
Технологические карты и другие генерируемые документы выгружаются в `EXCEL` либо при его отсутствии в `LibreOffice`.

## Настройки
В строковом ресурсе `URI server` указан `URI`, по которому запущен сервис
[Production process service](https://github.com/Parshin-Denis/production-process-service.git).

## Управление
Для начала работы после первого запуска приложения нужно авторизоваться в нем под именем `admin` с паролем `admin`. Без авторизации доступен только просмотр.
Для доступа к списку пользователей нужно дважды щелкнуть на имени текущего пользователя в верхнем правом углу окна приложения.
Доступ к этому списку есть только у пользователей с ролью `ROLE_ADMIN`.\
Общий список ролей и прав пользователей:
* `ROLE_ADMIN` - полный доступ к функционалу
* `ROLE_EDITOR` - создание и редактирование технологических карт и всех необходимых для них элементов
* `ROLE_CARD_CREATOR` - создание и редактирование технологических карт
* `ROLE_SCREWING_SPECIALIST` - создание и редактирование инструментов завинчивания
* `ROLE_TOOL_CHECKER` - создание кампаний проверки инструментов и загрузка их результатов.
